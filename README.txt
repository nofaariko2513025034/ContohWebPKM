# EXPLORE NUSA — Website Wisata Gen Z

## Struktur
- index.html → struktur/konten website
- style.css → seluruh styling dan responsive layout
- script.js → animasi reveal, modal popup, back-to-top, dan parallax

## Cara menjalankan
1. Simpan ketiga file dalam satu folder.
2. Buka `index.html` di browser.
3. Internet diperlukan untuk Google Fonts dan foto Unsplash.

## Yang perlu diganti
- Nama destinasi dan tagline di `index.html`.
- Harga tiket, jam operasional, fasilitas.
- Link Google Maps.
- Link WhatsApp dan Instagram.
- Foto-foto Unsplash dengan foto destinasi asli.

## Catatan
Konten seperti harga, alamat, nomor WhatsApp, dan statistik pada template ini adalah contoh/demo. Sesuaikan dengan destinasi wisata sebenarnya.
